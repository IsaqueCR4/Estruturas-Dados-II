## 02/Fila Circular
Este projeto é um sistema simples de fila em C.

### Funcionalidades
Adicionar elementos na fila
Remover elementos da fila
Verificar se a fila está cheia
Verificar se a fila está vazia

### Como executar
Compile e execute o arquivo:

gcc main.c -o main
./main

### Funcionamento
A fila segue o conceito FIFO, onde o primeiro elemento que entra é o primeiro a sair.

No exemplo, os valores são adicionados e removidos seguindo a ordem de entrada.

A ordem de remoção será:

10
20
30
40
50

## 02/ O Call center
Este projeto é um programa simples que demonstra o funcionamento de uma pilha em Python.

### Funcionalidades
Adicionar números na pilha
Remover números da pilha
Mostrar os números removidos
Calcular a soma total dos números

### Como executar
Execute o arquivo:

python main.py

### Funcionamento
A pilha segue o conceito LIFO, onde o último número adicionado é o primeiro a ser removido.

Os números 10, 20, 30 e 40 são adicionados à pilha.

A ordem de remoção será:

40
30
20
10
